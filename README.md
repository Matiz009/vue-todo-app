# Vue Todo App

A todo app built with Vue.js.

## Screenshot

_Screenshot coming soon._

## Features

- Add tasks
- Double-click a task to edit it. Press Enter or click away to save.
- Tick a checkbox to mark a task as done
- Delete tasks

## Tech stack

Vue.js (Vue CLI), JavaScript, Bootstrap classes

## Getting started

```bash
git clone https://github.com/Matiz009/vue-todo-app.git
cd vue-todo-app
```

```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```

### Customize configuration
See [Configuration Reference](https://cli.vuejs.org/config/).

## Project structure

```
src/App.vue   Todo list component
src/main.js   App entry
public/       index.html and favicon
```
